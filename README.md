# 🚀 Portfolio Personal - Ivan Moreno

¡Bienvenido a mi repositorio de portfolio personal! Este proyecto refleja mi camino, habilidades y proyectos desarrollados como **Desarrollador Full Stack** con experiencia complementaria en **QA y Testing**.

Construido con un enfoque minimalista, profesional y en modo oscuro, inspirándose en interfaces de desarrollo modernas y limpias.

---

## 🛠️ Stack Tecnológico

Este portfolio está desarrollado utilizando tecnologías modernas del ecosistema web:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Control de versiones:** Git & GitHub

---

## ✨ Características del Portfolio

- **Modo Oscuro nativo** con detalles estéticos en azul moderno.
- **Diseño Responsive** adaptado para dispositivos móviles y computadoras.
- **Sección About / Sobre mí:** Descripción enfocada en mi perfil Full Stack y mi experiencia en QA/Testing.
- **Sección Resume / Experiencia:** Historial profesional y listado de certificaciones técnicas.
- **Sección Portfolio / Proyectos:** Tarjetas interactivas con enlaces directos a despliegues (deploys) y repositorios de GitHub.
- **Sección Testimonios:** Carrusel interactivo con recomendaciones reales de colegas de equipo.
